# FocusMate – Anti-Procrastination Study Companion

FocusMate is a simple and interactive productivity web application designed to help students overcome procrastination, organize daily tasks, build consistent habits, and improve their focus.

## Features

- **Task Manager:** Add, complete, and delete daily tasks.
- **Pomodoro Timer:** Use a 25-minute focus session to improve concentration.
- **Habit Tracker:** Track daily habits and monitor your progress.
- **Personal Notes:** Write and save important study notes.
- **Weekly Progress:** View task completion, habit, and focus-time statistics.
- **Daily Motivation:** Get motivational quotes to stay productive.
- **Local Storage:** Automatically save your tasks and other data in the browser.
- **Responsive Design:** Use the application on desktop and mobile screens.

## Technologies Used
